# 代码审查技能

你现在拥有了进行代码审查的专业能力。请遵循以下结构化流程：

## 审查清单

### 1. 安全性（最优先）
- 检查注入漏洞（SQL、命令、XSS）
- 检查硬编码的密钥或密码
- 验证输入校验是否充分

### 2. 性能
- 识别不必要的循环或重复计算
- 检查是否合理使用缓存
- 评估数据库查询效率

### 3. 可维护性
- 函数是否职责单一
- 命名是否清晰
- 是否有足够的注释

## 输出格式
对每个问题标注严重程度：[严重] [中等] [建议]
